In diesem Projekt geht es um das Erstellen eines Wörterbuches, das lateinischen, griechischen und evtl. auch englischen Lehnwörtern deutsche Entsprechungen gegenüberstellt.
1. Erstellen einer Wörterliste.
2. Per Batch mittels der KI Entsprechungen suchen und diese in einer Datenbank speichern.
3. Händisch eigene Entsprechungen in die Datenbank einpflegen.
4. Daraus ein Buch oder Internetseite erstellen.
